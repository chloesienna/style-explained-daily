STYLE EXPLAINED DAILY - EDITABLE LOOKBOOK

THIS IS NOT YET PUBLISHED. The HTML can be previewed locally. For editing through a friendly CMS, the folder must first be hosted in a GitHub repository.

SETUP (ONE TIME)
1) Create a GitHub account, if needed.
2) Create a PUBLIC GitHub repository named style-explained-daily-shop. Upload the CONTENTS of this folder to the repository root (including hidden .pages.yml).
3) In GitHub repository Settings > Pages, choose Deploy from a branch / main / root. Wait for a URL to appear.
4) Visit https://app.pagescms.org and sign in with GitHub; authorize/install the Pages CMS GitHub app for this repository.
5) Open the repository in Pages CMS. Choose Shop the Looks. Edit items, upload images, and save. The live site reads data/looks.json so published content updates when GitHub Pages redeploys.
6) Add the GitHub Pages URL under your Amazon Associates website/social media sources before relying on traffic to it.

UPDATING
In Pages CMS: Shop the Looks > Add item to the list > title + main image + description + product links + outfits > Save. If changes don't appear immediately, wait for GitHub Pages rebuild and refresh.
